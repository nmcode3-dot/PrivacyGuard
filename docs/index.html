Get started in about a minute

Install the downloaded folder in Chrome. You only need to do this once.

1

Download and unzip

Click Download for Chrome above. Open your Downloads folder and double-click PrivacyGuard-main.zip to extract it.

2

Open Chrome extensions

In Google Chrome, enter chrome://extensions in the address bar. Turn on Developer mode using the switch near the top-right.

3

Load PrivacyGuard

Click Load unpacked. Select the extracted PrivacyGuard-main folder — the one containing manifest.json.

If Chrome asks for permission, review the requested permissions before continuing. To update later, download and extract the latest version, then use Reload on the PrivacyGuard card in chrome://extensions.

What it helps you watch for

A set of practical checks in one small browser extension.

Form protection

Sensitive information alerts

Warns about common sensitive details, such as email addresses, phone numbers, payment-card patterns and exposed tokens, before supported forms are submitted.

Device awareness

Camera activity alerts

Notifies you when it detects a website starting a camera stream and offers a way to block camera access for that site.

Site checks

Website risk signals

Checks the current address for suspicious URL patterns and explains which signals affected its local risk rating.

At a glance

Live privacy dashboard

Shows detected camera activity and available browser permission states for camera, microphone and location.

Privacy comes first

PrivacyGuard is designed to work locally. It does not require an account or send your browsing history, form contents, camera feed, microphone audio or location coordinates to a PrivacyGuard server. Its checks are limited and best-effort: an alert or a low-risk rating cannot guarantee that a website is safe or that every form of tracking or camera access has been detected. Review Chrome's permission prompts and settings too.
